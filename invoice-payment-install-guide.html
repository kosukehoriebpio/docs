① SSH キーを GitHub に登録する 初回のみ

プラグインとリファレンスはセキュリティ上 SSH 認証でのみ取得できます。PCごとに1回だけ設定が必要です。

前提GitHub アカウントへの招待が完了していることを確認してください。招待が来ていない場合は堀江まで連絡を。

1-1. SSH キーを生成する

PowerShell を開いて以下を実行します。すでにキーがある方はスキップしてください。

ssh-keygen -t ed25519 -C "your@email.com" # → ファイル名・パスフレーズは全て Enter でOK

1-2. 公開鍵をコピーする

cat ~/.ssh/id_ed25519.pub # → 表示された「ssh-ed25519 AAAA...」の1行全体をコピー

1-3. GitHub に登録する

ブラウザで https://github.com/settings/ssh/new を開き、以下を入力して Add SSH key をクリックします。

項目入力値
Title自分のPC名（例: SRGWIN0173）
Key typeAuthentication Key
Keyコピーした公開鍵を貼り付け

1-4. 接続確認

ssh -T git@github.com # → "Hi xxx! You've successfully authenticated..." と表示されればOK

② プラグインをインストールする 作業リポごとに1回

Slack で受け取った install.ps1 を使って自動セットアップします。

2-1. install.ps1 を受け取る

担当者から Slack で install.ps1 ファイルを受け取り、任意の場所に保存します。

2-2. 作業リポのフォルダで実行する

cd C:\作業リポのパス .\install.ps1

実行すると以下が自動で行われます：

  • [1/4] plugins/invoice-payment/ にプラグインを clone
  • [2/4] .invoice-payment-references/ にリファレンスを clone
  • [3/4] .claude/skills/invoice-payment/ にスキルを登録
  • [4/4] credentials.local.json の雛形を配置
PowerShell の実行ポリシーエラーが出た場合 先に以下を実行してください：
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

③ バクラク API キーを設定する 初回のみ

3-1. credentials.local.json を開く

plugins\invoice-payment\credentials.local.json

3-2. apiKey を入力して保存する

{ "bakuraku": { "apiKey": "ここにAPIキーを入力", "environment": "production" } }

APIキーの取得先：バクラク管理画面 › Settings › API

⚠ credentials.local.json は絶対に Git にコミットしないでください .gitignore で除外済みですが、他人に送ったりクラウドに上げないよう注意してください。

④ 業務を実行する 毎月

4-1. 作業リポで Claude Code を起動する

claude # 作業リポのフォルダで実行

4-2. スキルを呼び出す

/invoice-payment ship # 全9ステップを通し実行 /invoice-payment ship collect # Step 1（収集）だけ実行
コマンド例実行内容
/invoice-payment ship全9ステップを通し実行
/invoice-payment ship collectStep 1: 請求書収集のみ
/invoice-payment ship extractStep 2: 読取・仕訳登録のみ
/invoice-payment ship checkStep 3: 内容チェックのみ
/invoice-payment ship fundStep 4: 残高確認のみ
/invoice-payment ship payStep 5: 振込データ作成のみ
/invoice-payment ship approveStep 6: 承認・振込実行のみ
/invoice-payment ship deliverStep 7: 完了報告のみ
/invoice-payment ship reconcileStep 8: 消込確認のみ
/invoice-payment ship taxStep 9: 税務処理のみ
Claude が各ステップを案内します。判断が必要な場面では確認を求められます。不明な点はそのまま Claude に質問してください。

更新方法

新しいクライアントが追加されたとき、またはプラグインのバージョンアップ時は再度 install.ps1 を実行するだけです。

.\install.ps1 # → インストール済みの場合は pull のみ実行（再インストール不要）
