security-audit プラグイン 導入マニュアル

v0.1.3 — 社内 Claude Code ユーザー向け（非公開）

導入の流れ（全体像）

  1. GitHub アカウントを作る（すでに持っている人はスキップ）
  2. 自分の GitHub ユーザー名を確認する
  3. スプレッドシートにユーザー名を記入する
  4. 担当者（堀江）からの招待メールを承諾する
  5. プラグインをリポジトリに導入する
  6. /security-audit で監査を実行する

このマニュアルについて

このページは、社内の Claude Code ユーザーが security-audit プラグイン を導入するための手順書です。GitHub アカウントを持っていない方でも、このページを最初から読み進めるだけで導入完了できます。

GitHubアカウントがない方
Step 1 から始める
アカウント作成 → ユーザー名確認 → 記入の順に進んでください
GitHubアカウントをすでに持っている方
Step 2 から始める
ユーザー名の確認方法から始められます

Step 1｜GitHub アカウントを作る

GitHubアカウントをすでに持っている方はStep 2へ

GitHub（ギットハブ）はソフトウェアのファイルを管理・共有するためのサービスです。このプラグインの配布に使用しています。無料で利用できます。

  • 1
    GitHub のサインアップページを開く

    ブラウザで https://github.com/signup にアクセスします。

  • 2
    メールアドレスを入力する

    普段使っているメールアドレス（会社のアドレスでOK）を入力し、「Continue」をクリックします。

  • 3
    パスワードを設定する

    8文字以上のパスワードを入力します。英字・数字・記号を組み合わせると安全です。

  • 4
    ユーザー名（Username）を決める

    GitHub 上でのあなたの名前です。半角英数字・ハイフンのみ使えます。日本語は使えません。

    例：taro-yamada、hanako-suzuki、bpio-tanaka

    ユーザー名は後から変更できますが、手間がかかります。
    社内向けには （名前のローマ字） や （名前）-bpio のような形が管理しやすいです。
  • 5
    メール配信の設定をする

    「Would you like to receive product updates…」は「n」（不要）を入力しても構いません。「Continue」をクリックします。

  • 6
    パズル認証を解く

    ロボットでないことを確認するためのパズルが表示されます。指示に従って操作してください。完了したら「Create account」をクリックします。

  • 7
    メールアドレスを認証する

    登録したメールアドレスに GitHub から確認メールが届きます。メール内の 8桁のコード を GitHub の画面に入力してください。

    メールが届かない場合は迷惑メールフォルダも確認してください。
  • 8
    アンケートをスキップして完了

    その後いくつか質問画面が表示されますが、「Skip personalization」をクリックして飛ばして問題ありません。

    GitHub のトップページ（ダッシュボード）が表示されればアカウント作成完了です。

    アカウント作成完了！　次は Step 2 でユーザー名を確認します。

Step 2｜GitHub ユーザー名を確認する

スプレッドシートに記入するのは GitHub のユーザー名（Username） です。メールアドレスや本名ではありません。

確認方法

  • 1
    GitHub にログインした状態でページ右上のアイコンをクリックする

    https://github.com を開き、右上にある自分のプロフィールアイコン（丸いアバター画像）をクリックします。

  • 2
    メニュー最上部に表示されている「Signed in as ◯◯◯」の ◯◯◯ がユーザー名です

    例えば「Signed in as taro-yamada」と表示されていれば、ユーザー名は taro-yamada です。

別の確認方法: GitHub にログイン後、https://github.com/settings/profile を開くと「Username」欄に表示されています。
ユーザー名と間違えやすいもの
  • 表示名（Display name）：本名やニックネームで設定できる名前。ユーザー名とは別物です
  • メールアドレス：記入不要です

Step 3｜スプレッドシートにユーザー名を記入する

  • 1
    スプレッドシートを開く

    担当者（堀江）から共有されたスプレッドシートのリンクをクリックして開いてください。

  • 2
    新しい行に自分の情報を入力する

    既存の行の下に1行追加して、以下の項目を入力してください。

    列入力内容例
    氏名氏名（漢字でOK）山田 太郎
    所属・チーム部署やチーム名BPOチーム
    GitHubユーザー名Step 2で確認したユーザー名taro-yamada
    メールアドレスGitHubに登録したメールアドレス（任意）t.yamada@example.jp
    招待ステータス空欄のままでOK（担当者が記入します）—
    備考何か連絡事項があれば—
  • 3
    入力が完了したら担当者に連絡する

    スプレッドシートへの記入が完了したら、堀江（kosuke.horie@sevenrich.jp）にその旨を連絡してください。担当者がアクセス権限を設定し、GitHub から招待メールを送ります。

    記入完了 → 担当者に連絡 → 招待メールが届くまで待ちます

Step 4｜招待メールを承諾する

  • 1
    GitHub から招待メールが届く

    GitHub に登録したメールアドレスに、件名「You've been invited to collaborate on BPIOLMS/claude-security-audit」というメールが届きます。

    メールが届かない場合は迷惑メールフォルダも確認してください。また、GitHub の通知設定によってはメールが届かないことがあります。その場合は次の手順で直接確認できます。
  • 2
    メール内の「View invitation」ボタンをクリックする

    GitHub のリポジトリ招待ページが開きます。

  • 3
    「Accept invitation」をクリックして承諾する

    リポジトリへのアクセスが有効になります。

    メールが届かない場合は、GitHub にログインした状態で https://github.com/BPIOLMS/claude-security-audit/invitations を直接開くと招待を確認・承諾できます。
  • 4
    招待承諾の確認

    https://github.com/BPIOLMS/claude-security-audit を開いてリポジトリの内容が見えれば、アクセス権限の設定は完了です。

    アクセス権限の設定完了！　次はプラグインの導入です。

Step 5｜プラグインをリポジトリに導入する

監査したいリポジトリのルートディレクトリで、以下のコマンドを順番に実行してください。

コマンドは Claude Code のターミナルや通常のターミナル（PowerShell / Terminal）で実行します。

1. サブモジュールとして追加

git submodule add https://github.com/BPIOLMS/claude-security-audit.git plugins/security-audit

2. SKILL.md を Claude Code に登録

mkdir -p .claude/skills/security-audit cp plugins/security-audit/skills/security-audit/SKILL.md .claude/skills/security-audit/SKILL.md

3. コミット

git add .gitmodules plugins/security-audit .claude/skills/security-audit git commit -m "system: add security-audit plugin"
コミットが完了したらインストール完了です。Claude Code を再起動して /security-audit が使えることを確認してください。

別のマシンでも使う場合

# 新規クローン時 git clone --recurse-submodules <your-repo-url> # 既存クローンに後から追加する場合 git submodule update --init --recursive

プラグインをアップデートする場合

git submodule update --remote plugins/security-audit cp plugins/security-audit/skills/security-audit/SKILL.md .claude/skills/security-audit/SKILL.md git add plugins/security-audit .claude/skills/security-audit git commit -m "system: update security-audit plugin"
