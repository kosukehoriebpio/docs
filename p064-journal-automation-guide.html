給与仕訳自動化 — 動作確認ガイド

株式会社Suage Japan 給与仕訳の自動生成 — テスト確認のお願い

このドキュメントについて

  • MF給与 → MF会計Plus仕訳取込の自動化GAS（Google スプレッドシートのプログラム）を開発しました
  • 2026年4月データで従来の仕訳と全行全セル完全一致を確認済みです
  • 開発用コピーで動作を確認していただき、問題なければ本体スプレッドシートに反映します
  • 鈴木さんの操作・確認が中心です。プログラムの知識は不要です

1. 概要 — 何をしたか

現行の手作業フロー

これまでは、以下のような手順で仕訳を作成していました。

  1. MF給与からCSVをダウンロードして「支給控除一覧表」タブに貼り付ける
  2. 「仕訳作成」タブのSUMIFS関数が各店舗・科目ごとの金額を集計する
  3. 集計結果を「仕訳取込用」タブに手動で整形・コピーする
  4. MF会計PlusへCSVとしてインポートする

この集計・整形の部分を、ボタン1つで自動化しました。

何が変わるか

メニューから「仕訳生成」を実行するだけで、「仕訳取込用」タブが自動生成されます。
手動での集計・整形・コピー作業が不要になります。

何が変わらないか

項目 変わらないこと
CSVの貼り付け手順 MF給与からダウンロードして「支給控除一覧表」タブに貼り付ける手順はそのままです
出力形式 MF会計Plus取込用の22列フォーマットはそのまま維持されます
インポート手順 仕訳取込用タブからCSV保存 → MF会計Plusへインポートするステップはそのままです
確認作業 生成後の内容確認（勘定科目・金額）は引き続き鈴木さんに行っていただきます
検証済み: 2026年4月データで、従来の手作業で作成した仕訳と自動生成した仕訳を全行全セル比較し、完全一致を確認しています。

2. 改善ポイント

列ズレ問題の解消

従来の方式では、MF給与から出力されるCSVの列の順番が変わると（例: 新しい項目が追加されて列が1つずれる）、 仕訳作成タブのSUMIFS関数が全行ズレてしまい、列の参照をすべて手修正する必要がありました。

新方式では「支給額」「健康保険」など列名（ヘッダーの文字）で列を特定します。 列の挿入や並び替えが発生しても修正は不要です。

新店舗対応の簡易化

従来は新しい店舗が増えるたびに、仕訳作成タブに行を手動で追加し、SUMIFS式を設定し直す必要がありました。

新方式では「店舗マスタ」タブに1行追加するだけで、新店舗の仕訳が自動的に生成されます。 関数の修正は一切不要です。

自動検証の追加

仕訳生成と同時に、以下の確認が自動で実行されます。問題があれば結果ダイアログに表示されます。

検証項目 チェック内容
借方/貸方バランス 全仕訳行の借方合計と貸方合計が一致しているかを確認
未払金と振込支給額の突合 未払金（給与として計上した金額）と実際の振込支給額が一致しているかを確認
部門未設定者の検出 部門コードが設定されていない従業員がいた場合に通知

4. テスト手順

開発用コピー（テスト用スプレッドシート）で動作を確認してください。 4月分のデータが貼り付け済みの状態で準備してあります。

テスト用スプレッドシートのURLは、堀江からSlackでお伝えします。
本体のスプレッドシートは変更されませんので、安心してご操作ください。

1開発用コピーのスプレッドシートを開く

堀江からお伝えしたURLをブラウザで開いてください。Googleアカウントでのログインが必要です。

4月分の支給控除一覧データがすでに「支給控除一覧表」タブに貼り付けられています。

2「仕訳生成」を実行する

画面上部のメニューバーから 「給与仕訳」→「仕訳生成」 をクリックしてください。

メニューが表示されない場合: ページをリロード（キーボードの F5 キー、またはブラウザの更新ボタン）してください。 再読み込み後に「給与仕訳」メニューが表示されます。
初回実行時「承認が必要です」と表示された場合:
  1. 「許可を確認」をクリック
  2. Googleアカウントの選択画面でご自身のアカウントを選択
  3. 「このアプリはGoogleで確認されていません」と表示された場合 → 「詳細」→「（アプリ名）に移動」をクリック
  4. 「許可」をクリック
この承認操作は初回のみ必要です。2回目以降は表示されません。

3検証結果のダイアログを確認する

「仕訳生成」を実行すると、自動で検証結果のダイアログ（ポップアップ）が表示されます。

表示 意味 対応
[ OK ] チェック正常 問題ありません
[ INFO ] 参考情報（マイナス支給者の通知など） 確認のみ。通常は対応不要です

全項目が [ OK ] であることをご確認ください。 [ NG ] や [ ERROR ] が表示された場合は、堀江にSlackでご連絡ください。

4「仕訳取込用」タブを確認する

「仕訳取込用」タブを開くと、自動生成された仕訳データが表示されています。

  • 従来と同じ形式（22列）で出力されています
  • 勘定科目・補助科目・税区分・金額・摘要の内容をご確認ください
  • 確認ポイントの詳細はセクション5をご参照ください

5「原本突合」で従来の仕訳と比較する（任意）

メニューから 「給与仕訳」→「原本突合」 をクリックすると、 従来の手作業で作成した仕訳取込用タブと自動生成結果を全セル比較し、差分を表示します。

「差分ゼロ — 完全一致」 と表示されれば、従来の仕訳と完全に一致しています。

4月分では完全一致を確認済みですが、念のため目視でもご確認いただけますと幸いです。

5. 確認してほしいこと

以下の観点で「仕訳取込用」タブの内容をご確認いただけますでしょうか。経理のご専門家として鈴木さんのご判断をお聞かせください。

  1. 勘定科目・補助科目・税区分は正しいですか？
    各仕訳行の科目や税区分が、従来の仕訳と一致しているかご確認ください。
  2. 各店舗の金額は従来と一致していますか？
    店舗ごとの給与・社保・雇用保険等の金額が正しいかご確認ください。
  3. 摘要の表記（「正社員給与（渋谷）」等）は問題ないですか？
    摘要欄の文言が実務で使用している表記と合っているかご確認ください。
  4. 他に気になる点はありますか？
    気になる表現・不足している情報・使い勝手など、何でもお知らせいただけますと助かります。

ご確認後、Slackで堀江まで結果をお知らせください。「問題なし」「〇〇が気になる」など、ひとことで大丈夫です。

6. 新店舗が増えた時の手順

新店舗が開業した際は、以下の手順で対応できます。仕訳定義の修正は不要です。

  1. 「店舗マスタ」タブを開く
  2. 最下行に新店舗の情報を追加する
    店舗名・MF部門名・摘要表記（仕訳に表示される名前）・列キー（MF給与CSVの対応列名）・有効フラグ（TRUE）を入力してください。
  3. 「雑給店舗別マッピング」タブに新店舗のアルバイト給与列名を追加する
    MF給与CSVにおけるアルバイト給与の列名を追記してください。
  4. 以上で完了です
    次回の「仕訳生成」実行時から、新店舗の仕訳が自動的に生成されます。
初回の新店舗対応時は、堀江と一緒に確認しながら設定することをお勧めします。不明な点はSlackでお知らせください。
