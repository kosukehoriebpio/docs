1. プロジェクト概要

p001（研修事業プロジェクト）は、BPIOが経理BPO事業で蓄積してきた実務ノウハウを体系化し、 外販可能な研修・教育プロダクト「ビピトレ（仮）」として展開する事業プロジェクトです。

2025年末にスタートし、経理BPO基礎・労務BPO基礎コンテンツを完成。 2026年5月から経理BPOアドバンスコンテンツの制作を進めています。

一言で言うと： BPIOの暗黙知を教材化し、「人を育てられるBPO会社」として外部に研修事業を展開する。 研修が既存BPO・コンサル事業のフロントエンドにもなる二重収益構造。

2. なぜこの事業を始めたか（作成背景）

2-1. BPO事業の強みと暗黙知の課題

BPIOは経理業務の包括サポートを提供してきた中で、 コンサルタントとオペレーターの判断分岐 （「この顧客はコンサル先行か代行先行か」「どのタイミングでコンサルに移行するか」）など、 属人的なスキルが社内に蓄積されてきました。

この「暗黙知」は現在ベテラン担当者の頭の中にしかなく、新人教育のコスト増大・品質のバラつきを生んでいます。 これを形式知化して教材にすることが事業の出発点です。

2-2. 市場の構造的な問題

  • 経理人材の構造的不足：業務細分化により全体像を把握できる人材が希少
  • マニュアル教育の限界：「思考停止した作業者」を生みやすく、イレギュラー対応力が育たない
  • OJTの属人化：指導者によって品質がバラバラ、指導コストが高い

2-3. 事業開始のきっかけ：CCIFでの需要確認

研修事業を立ち上げる大きなきっかけのひとつが、JVパートナーであるCCIFへのサービス提供です。 CCIFとの連携を通じて、経理・労務BPOの現場で研修コンテンツに対する具体的な必要性・需要があることが確認できました。 このJV向けの実需から事業をスタートさせています。

2-4. 現フェーズ：JV向けサービスが主軸

現時点ではCCIF等のJVパートナー向けのサービス提供が主軸です。 不特定多数への積極的な外販展開は数年先を想定しており、まずはパートナー環境での品質検証・フィードバック収集を優先します。

「人を育てられるBPO会社」というブランドポジションは将来的な差別化要因として育てていく方針です。

4. コンテンツ構成と制作状況

研修コンテンツは2種類で構成されます：

  • 座学コンテンツ（〜とは）：業務の概要・目的・全体像を解説するスライド動画
  • 実践コンテンツ（実践）：実際のシステム操作・判断フローを演習形式で習得

Phase 1A：経理BPO基礎 ✅ 完了

スタンダード座学・経理実務のすべてのコンテンツを完成。

区分コンテンツ状況
スタンダード座学（5本） バリューチェーン / 経理業務基礎 / クラウドシステム / BPO基礎 / セキュリティ ✅ 完了
経理実務（12本） 売上請求書 / 入金消し込み / 立替経費 / 請求書振込 / 給与振込 / 納税管理 / 資産表作成（各座学＋実践） ✅ 完了

Phase 1B：労務BPO基礎 ✅ 完了

労務BPO向けの基礎コンテンツ（勤怠管理・給与計算・賞与計算・年末調整・タレントマネジメント等）をすべて完成。

Phase 2：経理BPOアドバンス ▶ 進行中（2026年5月〜）

経理BPO基礎の次のステップとして、より高度な実務判断・上位業務を扱うアドバンスコンテンツを制作中。
  • コンサル分岐判断の形式知化（コンサル先行型 vs 代行先行型の見極め）
  • 事業計画（予実管理）・稟議対応・購買管理等の高度業務
  • イレギュラー対応・複雑ケースの実践演習
